# Задание 2

### Архитектура решения для подготовки и получения отчётов
Для подготовки отчётов предлагается OLAP БД ClickHouse, в которую складываются данные из CRM, а также данные телеметрии. Поскольку одна из текущих проблем компании - деградация производительности БД PostgreSQL, в которой хранятся данные датчиков, то имеет смысл в качестве хранилища данных телеметрии использовать не PostgreSQL, а всё тот же ClickHouse.

Изменения архитектуры отражены на [диаграмме C4](./BionicPRO_C4_model.drawio.xml).

### Airflow DAG
В рамках задания был реализован DAG в Airflow, который запускается по расписанию. Скрипт расположен в каталоге `dags/bionicpro-dag.py` в корне проекта.

В качестве источников данных используются две БД - БД CRM (PostgreSQL) и БД телеметрии (ClickHouse). Скрипты инициализации и заполнения данными этих БД можно посмотреть в каталогах `crm-db` и `telemetry-db` соответственно.

После загрузки и трансформации данные сохраняются в OLAP БД ClickHouse. Скрипт инициализации БД находится в каталоге `olap-db`.

Данные в OLAP БД загружаются по расписанию - каждые 5 минут.

Веб-интерфейс Airflow после запуска через docker-compose доступен по адресу [http://localhost:7070](http://localhost:7070).

### Бекенд
Разработан бекенд на Java для генерации отчётов. Бекенд расположен в каталоге `backend` в корне проекта. 

В бекенде реализовано ограничение доступа - обратиться к эндпойнту генерации отчётов могут только пользователи с ролью `prothetic_user`. Так же бекенд генерирует отчёт только по данным текущего пользователя, данные других пользователей посмотреть нельзя.


### Фронтенд
На фронтенде улучшена безопасность путём замены Code Grant на PKCE.

Также на фронтенде реализован механизм получения и выгрузки отчёта для текущего пользователя. Для большей наглядности на страницу добавлен фильтр по датам, в пределах которых генерируется отчёт. В настоящее время все тестовые данные сгенерированы на две даты - 21.10.2025 и 22.10.2025. Соответствено, можно менять даты/время в фильтре и наблюдать, как меняются данные в отчёте.

### Запуск готового решения
Весь проект целиком можно запустить командой
```bash
docker-compose up -d
```
из корня проекта.

- Фронтенд доступен по адресу [http://localhost:3000](http://localhost:3000).
- Keycloak доступен по адресу [http://localhost:8080](http://localhost:8080).
- Бекенд доступен по адресу [http://localhost:8000](http://localhost:8000).
- Веб-интерфейс Airflow доступен по адресу [http://localhost:7070](http://localhost:7070).
