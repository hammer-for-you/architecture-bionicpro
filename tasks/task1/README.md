# Задание 1

### Повышение безопасности системы

- Для повышения безопасности системы я предлагаю использовать Keycloak. Это позволит унифицировать доступ в систему BionicPRO, в том числе и из других стран (посредством User Federation).
- Поддержка внешних провайдеров аутентификации так же будет осуществляться посредством Keycloak.
- Для исключения передачи access и refresh токенов на фронтенд я предлагаю воспользоваться паттерном Backend For Frontend. Токены будут храниться на "промежуточном" бекенде, который будет осуществлять всё общение с Keycloak. На фронтенд будет приходить только сессионная HttpOnly cookie.

Данные предложения отображены на [диаграмме C4](BionicPRO_C4_model.drawio.xml).
